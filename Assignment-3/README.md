# MATLAB App Designer — Assignment 3

26 callback-only `.m` files corresponding to Problems 1–26 from the uploaded assignment.

Open **App Designer → Code View**, create the specified button or dropdown callbacks, and paste the matching function contents. Each file is callback source, **not** a standalone runnable GUI app or `.mlapp` file.

Component names used in each file are named in the header comment; set these exact names in **Component Browser**. All text inputs are Text Edit Fields; set dropdown Items as directed in each file. For Problems 24–26, add the app properties in the header.

Test both valid and invalid inputs and capture screenshots, as the assignment requires.

**Caution:** Example currency rates are demonstration values, not live FX quotations. Login credentials in Problem 26 are for learning only, not production authentication.
