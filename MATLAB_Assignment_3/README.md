# MATLAB Assignment 3

Solutions for 26 IT Workshop MATLAB UI problems. Each `.m` file opens its own `uifigure` GUI when run in MATLAB. These are programmatic UI files, not native `.mlapp` files; MATLAB runtime verification is still required.

## Run

Open any problem `.m` in MATLAB, add the folder to the path, and run its named function, e.g. `Problem01_Calculator`.

Problem 21 uses illustrative fixed exchange rates. Problem 26 demonstrates hard-coded sample credentials for coursework only.
